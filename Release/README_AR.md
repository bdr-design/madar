# نسخة الإطلاق · VENTORA

هذا المجلد يحفظ هوية نسخة الإطلاق كما اعتمدها المالك:

| الملف | الاستخدام |
|---|---|
| `launch-art.png` | صورة الإطلاق العريضة: شاشة الإقلاع وخلفية شاشة الدخول (`LaunchArt` في Assets.xcassets) |
| `app-icon.png` | أيقونة التطبيق: حرف V بالبحر والطريق والطائرة (`AppIcon-1024.png` بعد تصغيرها إلى 1024) |
| `logo-full.png` | الشعار الكامل للمتجر والمواد التسويقية |

## كيف تُبنى نسخة الإطلاق

مصدر واحد بنسختين:

- **نسخة التطوير** (`build362-unsigned-ipa.yml`): فيها أدوات التحديث والتشخيص ومركز التحكم.
- **نسخة الإطلاق** (`ventora-release-ipa.yml`): نفس اللعبة، وفيها:
  - `GHEdition = release`، فلا تظهر للاعب صفحات التحديثات وصحة اللعبة ومركز التحكم، ولا بطاقة التحديث ولا خيارات مدة الحفظ، ولا يمكن تثبيت ملفات تحديث (التحديث من المتجر) ولا فحص الصفحة من Safari.
  - ملفات اللعبة مضغوطة ومعمّاة (esbuild)، ثم مشفرة AES-256-GCM بمفتاح يُولَّد لكل بناء، ويفكها التطبيق في الذاكرة فقط. أي ملف معدَّل أو غير مشفر يُرفض.
  - ملفات الحفظ مختومة بختم HMAC، فالحفظ المعدَّل بأدوات الجيلبريك يُرفض وتفتح اللعبة مسار الاسترداد.
  - حارس الأموال: أرصدة الشركات والأسهم وقيمة المجموعة والديون لا تتغير إلا داخل عمليات اللعبة، وأي قيمة يغيّرها محرر ذاكرة تعاد إلى قيمتها الصحيحة.

الأدوات: `tools/release/build-release-webapp.cjs`، والاختبارات: `tests/release/`.
